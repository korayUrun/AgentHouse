A card per session

Each Claude Code session gets its own house, named after the project. The chimney smokes while it works; a banner drops when a long task finishes.

Click to jump back

Claude is waiting for permission? Click the card and land in the exact terminal that owns the session.

📊

Local usage estimates

Token counts and rough cost per session, computed by reading transcripts on your disk — never by calling any API.

Observe-only, verifiably local

Nothing leaves your machine. The only networking code in the app is a listener bound to 127.0.0.1. No analytics, no telemetry, no update checks. The source is public — check for yourself.

Claude Code is never touched. AgentHouse adds one observe-only hook command to ~/.claude/settings.json (your existing settings are merged, backed up first, and fully restored on uninstall):

curl -s --max-time 1 -X POST http://127.0.0.1:48756/event \
  -H 'Content-Type: application/json' -d @- || true

It times out after one second and always succeeds, so Claude Code is never blocked — even when AgentHouse isn't running. It returns nothing, so it can never approve, deny, or modify what Claude does.

Stateless. Events live in memory only. The app writes nothing to disk except its own UI preferences.
